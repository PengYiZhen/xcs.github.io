Cocos Creator 接入 ​

1. 安装客户端 SDK ​

推荐使用 colyseus.js（TypeScript 项目最顺滑）。

2. 连接服务端 ​

服务端默认地址（本地）：http://localhost:2567

3. 登录并获取 JWT ​

先调用 HTTP 登录接口获取 JWT（详见 API 概览），再加入需要鉴权的房间。

4. 加入房间并收发消息 ​

示例流程：

  • joinOrCreate(roomName, { token })
  • room.onMessage("xxx", cb)
  • room.send("xxx", payload)

  • 真机/微信小游戏域名与 HTTPS 限制
