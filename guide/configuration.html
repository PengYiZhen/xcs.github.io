配置说明 ​

核心配置入口 ​

  • 应用配置：src/app.config.ts
  • 环境与数据库：src/config/index.ts
  • 小游戏参数：src/config/minigame.ts
  • 路由前缀：src/routes/index.ts

常用环境变量 ​

服务与数据库 ​

env
PORT=2567
DB_TYPE=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=your_password
DB_DATABASE=your_database
DB_SYNC=true

Redis 与 JWT ​

env
REDIS_HOST=localhost
REDIS_PORT=6379
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRES_IN=1h
JWT_REFRESH_SECRET=your_refresh_secret_key
JWT_REFRESH_EXPIRES_IN=7d

房间与聊天 ​

env
CHAT_ROOM_MAX_CLIENTS=5000
CHAT_WORLD_REDIS_CHANNEL=colyseus:chat:world
LOADTEST_ROOM_MAX_CLIENTS=10000
LOADTEST_ROOM_ENABLED=true

实践建议 ​

  • 生产环境关闭 DB_SYNC，改为迁移脚本。
  • 为 JWT_SECRET、数据库密码、Redis 密码使用高强度密钥。
  • 多实例部署时启用 Redis 并统一 CHAT_WORLD_REDIS_CHANNEL。
